# qFoldIT Scientific Environment & Gameplay Modes

**Version:** 1.0
**Status:** Cross-engine capability contract alignment

The Web runtime provides browser-native scientific visualization and interactive mission presentation using GPU/WebGL/WebGPU-capable techniques where available.

## Scientific environment

Aligned capability family:

- particles;
- liquid/fluid visualization;
- volumetric effects;
- scalar/vector fields;
- thermal and energy fields;
- diffusion/dissolution/reaction visualization;
- scientific, transparent, bio and reactive materials.

## Gameplay modes

The Web surface supports the same mission semantics for:

- Research Campaign;
- Arena Challenge;
- Co-op Lab;
- Sandbox Lab;
- Validation Duel;
- Build Mode;
- Racing Mode.

Build Mode is intended for spatial assembly and constraint satisfaction. Racing Mode is intended for time/route/process optimization and scientific parameter search.

## Quantum scheduling

Web sessions consume the canonical QOS policy and record quantum decisions/events without making the browser a scientific authority.

## Runtime boundary

Scientific computation and authoritative validation remain external services. Browser rendering is a scientific interaction and visualization surface.
