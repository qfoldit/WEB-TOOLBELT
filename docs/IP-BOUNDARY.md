# qFoldIT WEB Toolbelt IP Boundary

This repository is an intentionally public browser/runtime adapter surface. Published source remains governed by its applicable open-source license and attribution terms.

## Public boundary

The repository contains browser-native scene, visualization, UAG adapter, MCP/WebMCP and reusable runtime integration mechanisms intentionally published by qFoldIT.

## Private boundary

Confidential customer workflows, private mission policies, protected scientific references, credentials, signing material and undisclosed commercial algorithms belong in private qFoldIT repositories.

## Scientific boundary

Browser interaction, local physics and visualization do not establish scientific validity. Scientific evidence remains authoritative in the configured qFoldIT scientific validation service.

## Provenance

Production releases should preserve commit SHA, author, review reference, release identifier, artifact hashes and the corresponding qFoldIT IP evidence registry version.

## Third-party rights

Web libraries, browser platforms, external scientific projects, datasets and third-party assets retain their respective licenses and intellectual-property rights. This repository does not grant rights to third-party brands or assets.
