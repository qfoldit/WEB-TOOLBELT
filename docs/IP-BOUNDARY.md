# qFoldIT Web Toolbelt IP Boundary

This repository is an intentionally public runtime adapter surface. Its published source remains governed by the repository's applicable open-source license and attribution terms.

## Public boundary

The public Web Toolbelt contains browser-native execution, scientific-state visualization, telemetry abstractions, WebMCP boundaries and reusable adapter interfaces that qFoldIT intentionally publishes.

## Private qFoldIT boundary

Confidential customer workflows, private mission policies, protected scientific references, credentials, signing material and undisclosed commercial algorithms belong in private qFoldIT repositories and infrastructure.

## Scientific boundary

Browser interaction, local physics and visualization are not scientific authority. Scientific validity remains the responsibility of qFoldIT scientific services and the evidence contract.

## Provenance

Production releases should preserve commit SHA, author, review reference, release identifier, artifact hashes and the corresponding qFoldIT IP evidence registry version.

## Third-party rights

Three.js, Rapier.js, browser APIs, external scientific systems, datasets and assets retain their respective licenses and intellectual-property rights. This repository does not grant rights to third-party content.
