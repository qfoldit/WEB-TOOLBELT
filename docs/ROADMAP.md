Canonical state, tool registry, browser bridge, Three.js, Rapier, Gateway client, DropleX adapter contract.

Authenticated Gateway, gRPC-backed services, autoresearch, bio-ml, rosetta, quantum-adapter, plant.

Keep canonical state and capability contracts aligned with UEFN, Unity, and UNIGINE Toolbelts.

## Phase 6 — AI-native interaction
Capability discovery, structured execution, observation-driven feedback, experiment replay, human/AI collaboration.
