## Neil Voss / VossLab

**Work referenced:** Virtual-Lab-Simulation  
**Project:** https://github.com/qfoldit/Virtual-Lab-Simulation  
**Attribution:** Neil Voss / VossLab

The project is acknowledged as a reference for browser-based laboratory simulation, scientific visualization, and 3D interaction. qFoldIT WEB-TOOLBELT uses an adapter-oriented integration boundary so that such scientific simulation systems can remain external to the browser runtime.
